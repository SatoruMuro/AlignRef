Starting a new browser workflow?

AlignRef2 Web beta is the current recommended browser workflow. It includes its own automatic rigid registration and manual refinement; MultiStackReg is not required. It is not presented as an algorithmically equivalent replacement for previous analyses.

これからブラウザで作業する場合はAlignRef2を推奨します。自動位置合わせと手動補正を同じ画面で行えます。過去の解析と同じアルゴリズム・結果を保証するものではありません。
