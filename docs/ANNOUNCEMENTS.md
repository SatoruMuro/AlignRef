## GitHub / Web — 日本語

AlignRef2 Web betaを公開しました。組織の連続切片などの2D画像を読み込み、自動位置合わせ、結果の確認、手動補正、共通範囲の切り抜き、保存までをブラウザ内で行えます。インストールは不要で、読み込んだ画像はサーバーへアップロードされません。

JPG・PNGと、8/16-bit grayscale・RGBの一部のTIFF形式に対応します。16-bit入力も表示・位置合わせ・出力は8-bitです。Chrome / Edgeで動作確認しています。まずはTry demo datasetからお試しください。日本語・英語の使い方を用意し、旧AlignRef + MultiStackRegの手順もLegacy workflowとして残しています。

## GitHub / Web — English

AlignRef2 Web beta is now available. Load serial 2D images, run automatic rigid registration, review adjacent sections, refine alignment manually, crop and export—all in your browser. No installation is required, and user-loaded images are not uploaded to a server.

Input includes JPG, PNG and a tested subset of 8/16-bit grayscale and RGB TIFF. Display, registration and export use 8-bit data, including for 16-bit input. The app has been checked in Chrome and Edge. Start with the demo dataset and the Japanese or English guide. The original AlignRef + MultiStackReg instructions remain available as the Legacy workflow for reproducibility and compatibility with previous analyses.

- [Launch AlignRef2](https://satorumuro.github.io/AlignRef/)
- [English guide](https://satorumuro.github.io/AlignRef/guide/en.html)
- [日本語ガイド](https://satorumuro.github.io/AlignRef/guide/ja.html)
